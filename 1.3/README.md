# 1.3 Comunicación síncrona, APIs REST y contratos de datos

Aquí se conserva el material de REST, intercambio síncrono y contratos de datos.

La API Laravel de la raíz expone [rutas JSON](../routes/api.php) que responden a cada solicitud HTTP. El contrato específico de inscripción está en [`2.2/docs/CONTRATO_JSON.md`](../2.2/docs/CONTRATO_JSON.md). La ubicación de sus componentes se relaciona con la arquitectura de [1.4](../1.4/README.md).

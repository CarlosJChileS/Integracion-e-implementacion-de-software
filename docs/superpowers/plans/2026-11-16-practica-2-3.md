**Goal:** Add an authenticated Laravel adapter that converts two ILIA enrollment payload formats into the existing `EnrollCourseData` contract, with strict normalization and validation.

**Architecture:** A student-scoped translator service owns both source mappings and canonical validation. A new API endpoint exposes normalized JSON without writing an enrollment; clients then use the unchanged `/api/enrollments` contract. Practice 2.3 documentation records field mapping, examples, errors, tests, and the component diagram.

**Tech Stack:** Laravel 13, PHP 8.3+, Form Requests, Laravel Validator, immutable `EnrollCourseData`, PHPUnit.

## Global Constraints

- Preserve the existing authenticated `POST /api/enrollments` JSON contract.
- Do not commit `.env`, passwords, tokens, or other live credentials.
- The translator must reject malformed, ambiguous, missing, non-string, or unknown-reference values explicitly.
- Source A is a flat legacy ILIA enrollment object; Source B is a nested partner portal object.

## Review Focus

- Leading/trailing whitespace and mixed case normalize consistently to the catalog format.
- Missing or numeric course/cohort values fail validation without coercion.
- Unknown course slugs and cohort codes fail before an enrollment is written.
- Extra/conflicting keys are rejected instead of silently ignored.
- Omitting the optional cohort produces canonical `cohort_code: null`.

# Práctica 3.1 · Gestor de estado con React Context

Aplicación móvil/web de Expo que comparte solicitudes entre el formulario, el contador y la lista con `useContext`. Ejecuta `npm install` y `npx expo start` desde esta carpeta para abrirla con Expo Go, o `npx expo start --web` para usar el navegador.

El código, el guion de exposición de 25 minutos y las evidencias están descritos en [el README de la práctica](../README.md).
